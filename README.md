## ✨ Features

*   **Zero Dependencies:** 100% vanilla HTML, CSS, and JavaScript. No `npm install` or node modules needed.
*   **Interactive Palette Generator:** Instantly create and tweak color schemes directly in the browser.
*   **Responsive UI:** Carefully styled with CSS @media queries to ensure a seamless experience across desktop, tablet, and mobile devices.
*   **Click-to-Copy:** Click on any color swatch to instantly copy its HEX or RGB code to your clipboard.
*   **Lightweight & Lightning Fast:** Bypasses heavy frameworks for instant load times and smooth performance.
